Evidence and the gate

How the lab turns "it works" into a claim someone else can check, and who gets to say yes.

Inside the courtroom

A court does not accept "trust me." It wants exhibits, a witness who can be cross-examined, and a judge who reads them and rules. When the evidence is not in yet, the case is adjourned, which is not the same as losing.

Steps 6 and 7 run the same way. docs/evidence.md holds the exhibits. docs/gate.md records the ruling.

✅

PASS

Proven. A command ran, the output is quoted, and a second person reran it.

❌

FAIL

It ran and the result contradicts the claim.

⏸️

OPEN

Not yet known. Unrun, or blocked by access. "A blocked credential is an access result, not a failure."

The evidence table

Look at how much the template demands per row. Each column closes a gap an overconfident author (human or AI) could slip through.

docs/evidence.md 
Every row is a claim with the command that proves it, the exit code you saw and
the person who reran it. A row without a reviewer is a hypothesis. A command
nobody ran is `OPEN`, never a failure and never a pass.

PLAIN ENGLISH

Each row pairs a claim with the command that proves it...

...and a second person. Without that second person it is only a hypothesis.

Not run = OPEN. Never quietly counted as a pass, never unfairly counted as a fail.

 

Six columns: what you claim, how to check it, the exit code, a copied line of real output, who reran it, and the verdict.

The gate: robots observe, humans decide

Step 7 opens a pull request and fills docs/gate.md. The template draws a hard line between automated checks and approval.

docs/gate.md 
## What the automated checks observed

| Check | Observed | Is it an approval? |
| --- | --- | --- |
| `TEMPLATE — CI job` | `TEMPLATE — what it actually ran` | No |
| `TEMPLATE — review bot` | `TEMPLATE` | No |

## What the human read

- Success check proven by this diff: `TEMPLATE — quote the line from intent.md`
- Boundary touched by this diff: `TEMPLATE — quote the line, or NONE`
- Line from the diff that decided it: `TEMPLATE — quoted`
PLAIN ENGLISH

First, list what the machines did.

 

For each automated check: what it is, what it actually ran, and whether that counts as approval.

(Table divider.)

The CI job: pre-filled answer, No. Green CI is an observation.

An AI review bot: also No. It is printed in the template so nobody can forget.

 

Then, what a person actually read.

 

Which success check from intent.md this change proves, quoted word for word.

Whether it touches the fence. If not, write NONE explicitly.

The exact line of the diff that made up the reviewer's mind.

⚠️
Old output is not fresh evidence

The gate template ends with: "Do not treat this record, an agent claim or historical output as fresh evidence." Yesterday's green test run says nothing about today's code. Rerun it.
