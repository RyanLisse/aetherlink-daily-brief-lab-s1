`intent.md` and `progress.md` are project convention files; their presence at

PLAIN ENGLISH

The title of the note.

 

The @ is an import: "paste the whole of intent.md in here."

Also paste in the current scoreboard.

Also paste in the contribution rules.

 

A warning for whoever edits this file later: just having intent.md and progress.md in the folder does nothing.

The assistant only reads them because of the @ lines above.

So do not delete those lines. The goal, the status and the rules have to arrive together...

Context is loaded, not remembered

An AI model only "knows" what is in its context window right now. If a rule matters every session, make it load automatically instead of hoping you will remember to paste it.

AGENTS.md: the rules that stop AI from bluffing

Three of the seven rules are aimed squarely at the ways AI assistants go wrong.

AGENTS.md 
2. Verify the current state with the relevant command. Do not invent evidence, exit codes, screenshots or run results. Quote actual output; mark unrun checks `OPEN`.
3. The agent you build is read-only by construction: no built-in tools, only the source tools you define, no write scope on any token. Never widen that.
4. Never put a credential, a token or private company data in this repository, a prompt or a document. Sample data lives in `sample/`.
PLAIN ENGLISH

No bluffing. Run the command; do not guess what it would say. If you did not run it, say OPEN. This targets AI's habit of confidently reporting "all tests pass" without running them.

No extra powers. "Built-in tools" are things like a shell or file editor. The brief agent gets none of them, only the read-only source tools you write.

No secrets. A token pasted into a prompt or committed to the repo can leak. Real tokens live only in a local .env file that Git ignores.

💡
Two kinds of agent, two sets of rules

There are two AIs in this lab: your coding assistant (which writes the code) and the brief agent (which the code becomes). AGENTS.md governs the first and fences in the second. Keeping them apart in your head is half the battle.
